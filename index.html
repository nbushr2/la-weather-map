Louisiana Weather & Hazards

Click the map or a pin for current conditions + hourly forecast. Use the layer control to turn on stations, METAR pins, rainfall, gauges, radar, alerts, and boundaries.
If a layer fails to load, it’s usually temporary service/CORS issues—other layers will still work.
What you’re seeing
• Radar = NWS MRMS base reflectivity
• Rainfall = MRMS QPE (estimated precip)
• Alerts = active NWS alerts
• “Current conditions” = nearest reporting station; forecast = NWS grid for that point
Tip: For SRCC-like behavior, click METAR/ASOS pins (airport stations).
